# Логотип ContentPilot

Официальный набор векторных и растровых версий логотипа ContentPilot.

## Файлы в папке

| Файл | Формат | Описание |
|---|---|---|
| `mark-light.svg` | SVG | Векторная иконка логотипа для светлой темы |
| `mark-dark.svg` | SVG | Векторная иконка логотипа для тёмной темы |
| `wordmark-light.svg` | SVG | Полный логотип (знак + текстовый блок «ContentPilot») для светлого фона |
| `wordmark-dark.svg` | SVG | Полный логотип (знак + текстовый блок «ContentPilot») для тёмного фона |
| `mark-light.png` | PNG | Растровая иконка высокого разрешения |
| `mark-foreground.png` | PNG | Растровый передний план для адаптивных иконок мобильных приложений |
| `splash-logo-light.png` | PNG | Логотип для заставки (splash screen) светлой темы |
| `splash-logo-dark.png` | PNG | Логотип для заставки (splash screen) тёмной темы |

## Фирменные цвета

- **Основной акцент (Primary Indigo)**: `#4F46E5` / `rgb(79, 70, 229)`
- **Вторичный акцент (Violet / Hover)**: `#6366F1` / `rgb(99, 102, 241)`
- **Тёмный текст / фон (Deep Ink)**: `#14172B` / `rgb(20, 23, 43)`
- **Белый контраст**: `#FFFFFF` / `rgb(255, 255, 255)`

## Фирменная типографика

- Гарнитура: **Manrope** (шрифт заголовков и текстового знака, начертание ExtraBold 800)
