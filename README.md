# SmartCanteen AI

Цифровая платформа управления школьным питанием: планирование рационов, партионный складской учет по принципу FEFO, детерминированное прогнозирование спроса, технологические карты по нормам СанПиН, автоматический расчет закупок и минимизация пищевых отходов.

## Возможности

- MealPredict: прогноз суточной потребности в блюдах на основе ожидаемой посещаемости, структуры спроса и категорий СанПиН.
- SmartStock (FEFO): партионный учет сырья с контролем сроков годности и приоритетным списанием ранних партий (First Expired, First Out).
- ProcurementPlanner: автоматический расчет дефицита сырья на основе суточного меню и остатков склада (+10% страхового резерва).
- WasteGuard: фиксация уравнения баланса смены (приготовлено = выдано + остаток + отходы) и расчет стоимости списаний.
- Публичный портал и терминал выдачи: бесконтактный просмотр меню по QR-коду, предзаказ и выдача порций по персональным кодам.

## Технологический стек

- Backend: Java 21, Spring Boot 3, Spring Security, Flyway, PostgreSQL 16.
- Frontend: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- Mobile: Flutter, Dart, Riverpod.
