## 3. Проверенный сценарий Демо (3 минуты)

1. **Регистрация / Вход**: `http://localhost:3000` — мгновенный вход почтой или Google кнопкой.
2. **Бренд**: В разделе «Бренд» нажатие кнопки **«Заполнить кофейню для демо (3 мин)»** заполняет:
   - Меню: *Сезонный латте Тыква-Пряности (320₽)*, *Капучино (250₽)*, *Флэт уайт (280₽)*.
   - Часы: `08:00 - 22:00`, Адрес: `ул. Ленина, д. 42`.
3. **Цель**: Выбор цели *«Продвинуть сезонный латте Тыква-Пряности»* → генерация 4 публикаций.
4. **Фактчекинг**:
   - Пост №3 генерируется с ценой *250₽*, система автоматически ловит несовпадение и ставит статус **`NEEDS_REVIEW`**.
   - Кнопка *«Опубликовать сейчас»* заблокирована.
5. **Исправление**: Нажатие *«Исправить цену на 320₽»* перепроверяет пост, переводит его в **`SCHEDULED`**.
6. **Публикация**: Нажатие *«Опубликовать сейчас»* отправляет пост в Telegram-канал и ставит статус **`PUBLISHED`**.
