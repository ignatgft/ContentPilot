# ContentPilot 2.0 — Архитектура системы

## 1. Назначение и контекст
**ContentPilot 2.0** — ИИ-маркетолог на автопилоте для малого бизнеса (первая ниша: спешелти кофейни).
Сервис автоматизирует полный маркетинговый цикл:
`Бизнес-цель → Стратегия → ИИ-генерация → Фактчекинг и сверка цен → Публикация по расписанию → Измерения → Рекомендации`.

## 3. Модули бэкенда (`com.contentpilot.*`)

| Пакет | Ответственность |
| :--- | :--- |
| `auth` | Регистрация, вход, Google ID токен, JWT фильтрация, хеширование паролей (BCrypt) |
| `brand` | Управление профилем бренда, факты (JSONB: меню, цены, график, адрес) |
| `campaign` | Создание маркетинговой кампании по заданной цели, расчет дат публикаций |
| `generation` | Генерация постов под площадки (Telegram, VK, Instagram) через Claude API |
| `verification` | Сверка цен с меню бренда, стоп-слова, лимиты символов |
| `post` | Управление публикациями, ручное утверждение, редактирование, статусная машина |
| `scheduler` | Фоновый планировщик `@Scheduled(fixedRate = 60000)`, защита от дубликатов |
| `publisher` | Интеграция с Telegram Bot API, логирование попыток в `publish_log` |
| `analytics` | Агрегация метрик охвата и формирование выводов на базе реальных данных |
| `config` | Spring Security, CORS, PasswordEncoder, RestClient |

## 4. Статусная модель публикации (`Post.status`)
```
[DRAFT] ──> [Verification] ──┬──> (Ошибки / расхождение цен) ──> [NEEDS_REVIEW] ──> [Approve / Edit]
                             │                                                          │
                             └──> (Все проверки пройдены) ──────> [SCHEDULED] <─────────┘
                                                                        │
                                                         (Время выхода наступило / Publish Now)
                                                                        │
                                                                        ▼
                                                                 [PUBLISHING]
                                                                        │
                                                         ┌──────────────┴──────────────┐
                                                         ▼                             ▼
                                                    [PUBLISHED]                    [FAILED]
                                                                                (до 3 попыток)
```
Emergency Button («Остановить всё»): переводит все `SCHEDULED` посты бренда в статус `PAUSED`.
