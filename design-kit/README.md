# ContentPilot design kit

- icons/: 26 stroke-иконок (24px, currentColor, stroke 1.8)
- logo/: знак и логотип для светлой и тёмной тем
- avatars/: 5 аватарок (бренд, владелец, SMM, ИИ-агент, агентство)
- platforms/: значки площадок (временные буквенные; заменить официальными по правилам площадок)
- banners/: баннеры 1200x630 для питча и превью ссылок
- tokens/: цвета, шрифт и размеры (CSS-переменные и JSON), темы светлая и тёмная через [data-theme="dark"]

Шрифт: Manrope (Google Fonts).
